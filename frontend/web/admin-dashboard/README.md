# 📊 Admin Dashboard

### 🧰 Stack

- React
- Tailwind CSS
- Recharts
- Framer Motion

### ⚙️ Lancer localement

⚠️ Ne pas oublier de mettre à jour l'`url` du backend au niveau des variables d'environnement si nécessaire

- Instller les dépendances

```shell
npm i
```

- Lancer l'app

```shell
npm run start
```
